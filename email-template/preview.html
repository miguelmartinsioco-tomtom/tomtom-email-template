TomTom email template v1

This is the HTML version of the Figma email template. Every customer notification uses the same four sections. Teams change only the text body. The logo, support pathways and footer stay the same, so every email reads as coming from one TomTom.

The four sections

  1. 1 TomTom logo Locked

    The header only says TomTom. Don't add a product or team name here.

  2. 2 Text body Editable

    The only part you change. Keep the styles as they are.

    • Title: the update in a few words
    • Name the product in the introduction
    • Say what changed, what to do and by when
    • Links list is optional
    • One primary button with a clear label
  3. 3 Support pathways Locked

    Points every reader to the Help Center, the one official place to ask. Don't replace it with a team mailbox. Includes the sign-off.

  4. 4 Footer Locked

    Privacy Policy, copyright and the no-reply notice. Only fill in the year and legal entity.

Before you send

  • Write a subject line and a preheader (the preview line in the inbox).
  • Replace every [bracketed placeholder] and check every link.
  • Host the logo PNG on a public HTTPS address and update its src.
  • Test on mobile, dark mode, Outlook and Gmail. Check contrast.
  • Never send passwords, API keys or other credentials by email.

Editing the HTML

  • Search the file for ✏️ EDITABLE. Change only what sits between that marker and ✏️ END EDITABLE.
  • Leave everything marked 🔒 LOCKED as it is.
  • The button appears twice: once for Outlook, once for other apps. Change the label and link in both.
  • The file uses tables and inline styles on purpose, because email apps don't support modern layout. Keep it that way.

Fonts in the email

  • Titles and buttons: Gilroy, falling back to Plus Jakarta Sans.
  • Body and captions: Proxima Nova, falling back to Figtree.
  • When an email app blocks web fonts (such as Outlook desktop), text shows in Arial, Helvetica, sans-serif.
